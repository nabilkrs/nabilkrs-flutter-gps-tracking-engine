Background location in Flutter is harder than it looks

The moment the screen locks or the app leaves the foreground, Android starts working against you. This kit exists so you don't have to fight it alone.

Screen lock kills updates

Location callbacks silently stop firing once the device sleeps, unless the service is configured correctly.

Battery optimizations throttle you

Android's power management can delay, batch, or drop location updates to save battery.

App backgrounded, GPS lost

Without a proper foreground service, the OS can suspend your app's location plugin entirely.

Manufacturer quirks

OEM battery managers (Xiaomi, Huawei, Samsung, etc.) each handle background apps differently.

location_service.dart 
import 'package:location/location.dart';
import 'package:flutter/foundation.dart';

class LocationService {
  static Future<void> init() async {
    await Location().start(
      interval: 15,
      accuracy: LocationAccuracy.high,
    );
  }

  static Stream<LocationData> stream() {
    return Location().locationStream;
  }
}
